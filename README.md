# GrBox — SECRET BOX®

Модульный гроубокс: сайт-конфигуратор с живой 3D-моделью, инженерными расчётами и базой знаний.

Сайт: **https://spektrasqe-svg.github.io/GrBox/**

## Как устроено

- Все страницы — автономные HTML поверх общего движка в `assets/site/`. Внешних зависимостей, кроме three.js (UMD/CDN), нет.
- **Единая конфигурация**: `product-state.js` хранит параметры сборки; её читают builder, 3D, `engineering.html` и `calculators.html`. Сохранённые конфиги мигрируют со старой схемы ключей автоматически.
- **Живая связка builder ↔ 3D**: конфигуратор шлёт конфиг в iframe через `postMessage`, 3D пересобирает сцену, не сбрасывая камеру.
- **`?bare=1`** — встраивание 3D без шапки сайта (используется в iframe на index и builder).
- Страницы товаров A/B/C показывают живую 3D текущей конфигурации (16:9 / 4:3 на мобильных).

## Разработка

```bash
# локально
python3 -m http.server 8000        # затем http://localhost:8000/
```

Проверки перед пушем: 0 uncaught exceptions в консоли на всех страницах, нет горизонтального
переполнения на 390/320 px, статический чекер ссылок без битых целей.

## Известные ограничения

- three.js подключён UMD/CDN (warning в консоли) — переход на ES modules в бэклоге.
- Маркетинговые цены («от 190 000 ₽») и расчётные (~248 000 ₽) пока не сведены.
- Ссылки «Москва · сборка под ключ» и «Стать дилером» в футере временные (`#order`).
- Картинки `assets/cab_*.jpg` загружены, но пока нигде не используются.
