# GrBox — SECRET BOX®

Модульный гроубокс: сайт-конфигуратор с живой 3D-моделью, инженерными расчётами и базой знаний.

Сайт: **https://spektrasqe-svg.github.io/GrBox/**

## Как устроено

- Все страницы — автономные HTML поверх общего движка в `assets/site/`. Внешних зависимостей, кроме three.js (UMD/CDN), нет.
- **`site-config.js` — единственный файл, который нужно править при запуске**: контакты, приём заявок, цены.
  - `contacts` — телефон, Telegram, e-mail, часы работы, адрес. Пустое поле → блок скрывается.
  - `leads.mode` — `telegram` (заявки падают в Telegram через свой релей из `deploy/telegram-relay.js`),
    `formspree`, `webhook`, `links` (без бэкенда: заявка собирается, отправка кнопками + копирование).
    Без `endpoint` любой режим молча откатывается в `links`.
  - `pricing.products` — стартовые цены комплектаций `base` / `full` / `max` (`null` → «Цена по запросу»);
    `pricing.book` — тарифы расчётного движка; `pricing.quick` — надбавки мини-конфигуратора на главной.
    Сейчас откалибровано под якоря: **минимум 80 000 ₽ · база 150 000 ₽ · топ 300 000 ₽**.
- **Воронка продаж**: `order.html` — форма заявки с автоматической сводкой текущей конфигурации.
  Ведут: футер, `#order` на главной, сайдбар и финальный шаг конфигуратора, карточки товаров. `?type=dealer` и др. предвыбирают тип запроса.
- **Единая конфигурация**: `product-state.js` хранит параметры сборки; её читают builder, 3D, `engineering.html` и `calculators.html`. Сохранённые конфиги мигрируют со старой схемы ключей автоматически.
- **Живая связка builder ↔ 3D**: конфигуратор шлёт конфиг в iframe через `postMessage`, 3D пересобирает сцену, не сбрасывая камеру.
- **`?bare=1`** — встраивание 3D без шапки сайта (используется в iframe на index и builder).
- Страницы товаров A/B/C показывают живую 3D текущей конфигурации (16:9 / 4:3 на мобильных).

## Разработка

```bash
# локально
python3 -m http.server 8000        # затем http://localhost:8000/
```

Проверки перед пушем: 0 uncaught exceptions в консоли на всех страницах, нет горизонтального
переполнения на 390/320 px, статический чекер ссылок без битых целей.

## Комплектации

Готовых моделей нет — продукт один и параметрический (размер задаёт покупатель), различается только наполнением:

| Комплектация | Цена «от» | Что входит |
|---|---|---|
| **БАЗА** | 80 000 ₽ | корпус, свет, вентиляция |
| **ПОЛНЫЙ ЦИКЛ** | 150 000 ₽ | + контроллер, климат, автополив, датчики, акустика |
| **МАКСИМУМ** | 300 000 ₽ | + ИБП, оборудование максимального класса |

## Известные ограничения

- three.js подключён UMD/CDN (warning в консоли) — переход на ES modules в бэклоге.
- Telegram задан номером (`contacts.telegramPhone`), а не @username — для полноценной ссылки лучше завести @ник.
- Почта и телефон пока не заполнены: на сайте только Telegram-канал связи.
- Картинки `assets/cab_*.jpg` загружены, но пока нигде не используются.
