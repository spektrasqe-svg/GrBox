# GrBox — GrowBox v3.1

Проект модульного гроубокса: инженерная документация, версии сайта и архив рабочих переписок.

## Структура

```
├── index-v3.html                                    # GrowBox v3.1 — PIANO / Digital Twin
├── GrowBox_v31_3D.html                              # GrowBox v3.1 — 3D (один файл)
├── GrowBox_v3_1_MOBILE_REALISTIC_3D.html            # GrowBox v3.1 — PRO Product 3D (мобильная реалистичная 3D)
├── GrowBox_v3_1_SITE_RECONSTRUCTED_20261005.html    # GrowBox v3.1 — Ultimate Engineering Edition (реконструкция сайта, 2026-10-05)
├── docs/
│   ├── growbox_v31_decisions.pdf                    # Документ решений v3.1
│   ├── growbox_v31_rev3.pdf                         # Описание v3.1, ревизия 3
│   └── Гроубокс_v3.1_rev2_полное_описание.pdf       # Полное описание v3.1, ревизия 2
└── chats/
    ├── chatgpt_Локальные-файлы-сайта.md             # Экспорт чата: восстановление файлов сайта, версии, баг addEventListener
    ├── chatgpt_Локальные-файлы-сайта_raw.json       # Сырые данные того же чата
    ├── alice_Стоимость-модульного-гроубокса.md      # Экспорт чата: разбор стоимости по компонентам, сравнение с Secret Box, акустика
    └── alice_Стоимость-модульного-гроубокса_raw.json
```

## Версии сайта

| Файл | Назначение |
|---|---|
| `index-v3.html` | Лендинг PIANO / Digital Twin |
| `GrowBox_v31_3D.html` | Полная 3D-инженерная версия (вращение, touch, камеры) |
| `GrowBox_v3_1_MOBILE_REALISTIC_3D.html` | Мобильная реалистичная 3D-версия продукта |
| `GrowBox_v3_1_SITE_RECONSTRUCTED_20261005.html` | Реконструкция сайта по инженерной базе (Ultimate Engineering Edition) |

Все файлы — автономные HTML (один файл, без внешних зависимостей). Открываются двойным кликом в браузере.

## Документация (docs/)

PDF-документы с описанием конструкции, решений по версии 3.1 и ревизиями спецификаций.

## Архив переписок (chats/)

Markdown-экспорты рабочих переписок с ChatGPT и Алисой + исходные JSON как источник истины. В переписках: восстановление файлов после потери репозитория, разбор себестоимости по компонентам (освещение, вентиляция, автополив, корпус), сравнение с Secret Box, решения по акустике (шумбокс, глушители, уплотнители, сэндвич-стены).

> Примечание: в экспорте ChatGPT часть выводов плагинов вырезана политикой публичных ссылок («The output of this plugin was redacted»). В экспорте Алисы — полный текст.
