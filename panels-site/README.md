# WALLFORM® — сайт по продаже и монтажу стеновых панелей

Статический сайт без сборщиков и внешних зависимостей (кроме Google Fonts).
Архитектура повторяет проверенную схему GrBox: автономные HTML поверх общего движка
в `assets/`, вся настройка — в одном конфиге.

## Структура

```
panels-site/
├── index.html            # Главная: hero, направления, каталог, расходники, мини-расчёт,
│                         # этапы монтажа, применения, цифры, портфолио, сравнение, FAQ, заявка
├── catalog.html          # Каталог: 8 категорий панелей + блок «как выбрать» + расходники
├── calculator.html       # Калькулятор сметы: материалы + расходники + работы → заявка с расчётом
├── montazh.html          # Монтаж под ключ: этапы, тарифы на работы, клей/каркас, FAQ
├── order.html            # Заявка: тип запроса, сводка из калькулятора (?cat= предвыбор категории)
└── assets/
    ├── site.css          # Единая дизайн-система (стиль «техпаспорт»: ink / cream / brass)
    ├── site-config.js    # ⚙ ЕДИНСТВЕННОЕ МЕСТО ПРАВКИ: бренд, контакты, цены, каталог, заявки
    ├── calc-engine.js    # Расчётный движок: панели с запасом, расходники по нормам, работы
    ├── leads.js          # Заявки: валидация, сохранение, отправка (telegram/formspree/webhook/links)
    └── main.js           # Шапка/футер из конфига, меню, рендер каталога/расходников, формы
```

## Что править при запуске

**Только `assets/site-config.js`:**

- `brand` — название, слоган, город
- `contacts` — телефон (`phone`, `phoneHref`), Telegram, WhatsApp, e-mail, часы, адрес
  (пустое поле → блок автоматически скрывается на всех страницах)
- `categories` — категории панелей: название, цена ₽/м², описание, текстура-заглушка
- `consumables` — расходники: название, упаковка, цена, норма расхода
- `works` — тарифы бригады (₽/м² и ₽/пог.м)
- `leads.mode` — приём заявок:
  - `links` (по умолчанию, без бэкенда): заявка собирается в текст,
    отправка кнопками Telegram / WhatsApp + копирование
  - `formspree` / `webhook`: POST на `leads.endpoint`
  - `telegram`: через свой релей (см. `leads.telegramChat`)
  - без `endpoint` любой режим молча откатывается в `links`
- `calc` — нормы расчёта: запас материала %, расход клея туб/м²

## Расчётный движок

`CalcEngine.compute(area, categoryId, method, opts)` возвращает:

- панели с запасом на подрез (по умолчанию 10%)
- расходники по нормам: клей (туб/м²), грунтовка (10 л на 50 м²), крепёж (набор на 10 м²),
  профили каркаса (1,2 пог.м/м²), герметик, теневой плинтус по заданному метражу
- работы: монтаж (клей / каркас), подготовка, демонтаж, плинтус, подсветка
- итог, ₽/м² и готовый текст заявки (`CalcEngine.toText`)

Калькулятор сохраняет последний расчёт в `localStorage` — страница заявки
прикладывает его к обращению автоматически.

## Дизайн

Стиль продолжает линейку SECRET BOX: тёмный фон `#2C2E33`, кремовый `#E8DCC8`,
латунь `#B69A6B`, шрифты Unbounded / Manrope / Roboto Mono, тех-рамки с «+»,
маркизы, номера секций, зерно поверх страницы.

Визуальные блоки используют интерьерные изображения Unsplash как референсы, а не как подтверждение выполненных объектов. Перед коммерческим запуском желательно заменить их на собственные фотографии изделий и монтажа. Стили классов `ph-wood`, `ph-stone`, `ph-slat`, `ph-fabric`, `ph-marble`, `ph-site` находятся в `assets/site.css`.

## Локальный запуск

```bash
cd panels-site
python3 -m http.server 8080
# http://localhost:8080
```

## Деплой (GitHub Pages)

Публикация автоматическая: workflow `.github/workflows/pages.yml` собирает Pages
при пуше в `main`. Локальный предпросмотр — `python3 -m http.server` из папки проекта.

- **Заявка из 3D-инструментов**: планировщик комнат и сборка стены передают эскиз в форму
