## 2. 🔴 Блокеры продаж (сделать до любого трафика)

### B1. На сайте нет телефона и почты
`site-config.js`: `contacts.phone = null`, `contacts.email = null`.
В DOM вообще **нет ни одной `tel:` / `mailto:` ссылки** — связь только Telegram (`t.me/+79521004044`).
Высокобюджетный продукт (80–300+ тыс. ₽) без звонка = потеря половины лидов: категория 35+ предпочитает созвон.

### B2. Заявки не отправляются автоматически
`leads.mode = 'telegram'`, но `endpoint = null` → молчаливый откат в `links`.
Форма «ОТПРАВИТЬ ЗАЯВКУ» собирает текст и показывает кнопки Telegram/копирования — это не отправка.
Релей `deploy/telegram-relay.js` (Cloudflare Worker, «схема C») **не развёрнут**.
Лид, нажавший «Отправить», получает дополнительный шаг — классическая точка потери.

### B3. Нет политики обработки персональных данных
`leads.privacyUrl = null`, ссылки на политику/оферту нигде нет.
Форма собирает имя/телефон — по 152-ФЗ нужен текст согласия со ссылкой на политику.
Плюс доверие: на премиум-сайте юридический блок в футере ожидаем.

## 3. 🟠 Конверсия и контент (по визуальному UX-разбору)

### K1. Нет social proof вообще
Ни отзывов, ни фото установленных боксов в реальных интерьерах, ни кейсов, ни упоминаний СМИ/экспертов.
Для high-ticket это **главный барьер доверия**. Есть готовый материал: `assets/cab_*.jpg`, `int_*.jpg` — но они не выложены в сюжет «реальный объект».

### K2. Комплектации без конкретного состава
Карточки «БАЗА / ПОЛНЫЙ ЦИКЛ / МАКСИМУМ» с ценами 80/150/300к не объясняют, **что именно входит за +70 000 и +150 000 ₽**.
Нужна сравнительная таблица: строки (корпус, свет, вентиляция, климат, автополив, резерв питания, монтаж…) × 3 комплектации с галочками.

### K3. Нет блока гарантий и логистики
Не указаны: гарантия (на что и сколько), сроки производства, доставка, монтаж/пусконаладка,
оплата (предоплата/рассрочка). Перед финальным CTA это снимает последние возражения.

### K4. CTA не объясняет следующий шаг
«Оставить заявку» без обещания: «перезвоним за 2 часа, пришлём расчёт за 24 часа, замер бесплатно».
Нет второго CTA для «не готовых купить»: PDF-каталог комплектаций / пример сметы / подписка.

### K5. «Инженерия, которую видно только когда нужна» — без картинок
Секция обещает инженерию, но не даёт визуального доказательства: рендеры узлов (акустический модуль,
тех-колонна), фото разрезов, схема тракта. У продукта есть 3D-модель — материал есть.

## 4. 🟡 SEO и техника

| # | Находка | Комментарий |
|---|---|---|
| T1 | Нет `sitemap.xml` / `robots.txt` | базовое SEO, делается за 5 минут |
| T2 | Нет структурированных данных (Product/Offer/FAQPage) | потеря rich-сниппетов в Яндекс/Google |

| T4 | `account.html` — «личный кабинет» на localStorage | без бэкенда вводит в заблуждение; лучше скрыть или переименовать в «Мои расчёты» (без регистрации) |
| T5 | `product-a/b/c.html` — редиректы без noindex | добавить `<meta name="robots" content="noindex">` |
| T6 | Картинки в старых форматах | `logo_20261005.jpg` 138 КБ, `cab_*.jpg` ~100 КБ каждый, preview.html 655 КБ — есть запас по webp/сжатию |

## 6. План работ (три волны)

### Волна 1 — продажи включаются (полдня)
1. Заполнить `contacts`: телефон, phoneHref, email, telegram → связь появится везде автоматически.
2. Развёрнуть релей заявок в Telegram (`deploy/telegram-relay.js`) → вписать `leads.endpoint`;
   либо временно `mode: 'formspree'` с бесплатным аккаунтом.
3. Добавить политику обработки ПД (страница `privacy.html`) + ссылки в футер и в форму.
4. `sitemap.xml` + `robots.txt` (+ noindex редиректам).

### Волна 2 — конверсия (1–2 дня)
5. Таблица комплектаций «что входит» (База/Полный/Максимум × 10–12 позиций).
6. Trust-блок: гарантия, сроки, доставка, монтаж, оплата — иконки + факты.
7. Соцдоказательства: мини-портфолио из `cab_*/int_*` фото + блок отзывов (даже 2–3 шт.).
8. Доработать CTA: обещание следующего шага + магнит (PDF-каталог / пример сметы).
9. Визуал инженерии: рендеры/схемы узлов в секцию «Внутри».

### Волна 3 — техника (по остатку)
10. Self-host three.js, webp-оптимизация, структурированные данные, переосмысление account.html.
